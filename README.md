# Quick Commerce Analytics — Power BI

A Power BI analytics project exploring customer behavior, sales patterns, delivery performance, and platform-level trends across India's quick-commerce market.

## 📊 Project Overview

This project uses publicly available Kaggle datasets to analyze quick-commerce activity across platforms such as **Zepto, Blinkit, Swiggy Instamart, BigBasket, Flipkart Minutes, Amazon Now, Dunzo, and JioMart**.

The dashboard focuses on turning raw transactional data into clear business insights using interactive Power BI reports.

## 🔍 Key Analysis

- Customer retention and repeat-order behavior
- Sales and revenue analysis
- Order trends by date and time
- Delivery time and distance analysis
- Customer satisfaction and ratings
- Payment method distribution
- Age-group revenue analysis
- Product/category demand
- Campaign cost and ROI
- Discount impact on order value
- Cross-platform performance comparison

## 📊 Data Source

The project uses publicly available Kaggle datasets related to Blinkit, Zepto-inspired grocery delivery, and quick-commerce analytics.

**Note:** The data is used strictly for portfolio and analytical purposes. It does not represent live, proprietary, or official company data.

## 🎯 Key Takeaway

The project demonstrates how Power BI can be used to transform transactional data into interactive business dashboards and identify patterns in **customer behavior, sales, delivery performance, profitability, and quick-commerce operations**.
